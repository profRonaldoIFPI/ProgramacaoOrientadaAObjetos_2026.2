# Programação Orientada a Objetos (POO) - TADS

Este repositório foi criado para acompanhar as aulas de **Programação Orientada a Objetos** do curso de TADS. Aqui, cada exemplo, exercício e material prático será organizado em um diretório por aula, facilitando o estudo e a revisão dos conteúdos apresentados em sala.

## Objetivo

- Organizar os exemplos de cada aula em diretórios separados.
- Fornecer um repositório de referência para os alunos acompanharem o que foi feito em sala.
- Estimular a prática de programação orientada a objetos usando exemplos claros e aplicáveis.

## Estrutura do repositório

- `aula-1108/`
- `aula-1808/`
- ...

Cada pasta de aula deve conter:

- exemplos de código
- exercícios resolvidos
- folhas de estudo ou anotações importantes

## Conteúdo programático

De acordo com o plano de ensino, o curso cobre:

- Programação Orientada a Objetos: histórico, linguagens e comparações com programação estruturada
- Conceitos básicos de OOP
- TypeScript: visão geral e introdução
- Variáveis, tipos primitivos, strings e conversão de tipos
- Operadores, controle de fluxo, entrada e saída, escopo de variáveis
- Orientação a objetos básicos: classes, objetos, instanciação, construtores, atributos e métodos
- Arrays e pacotes
- Encapsulamento e modificadores de acesso
- Herança, sobrecarga e sobrescrita de métodos
- Polimorfismo
- Classes abstratas e interfaces
- Tratamento de exceções
